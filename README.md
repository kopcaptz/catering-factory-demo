**Обе фирмы вымышленные.** Контакты ненастоящие (+34 600 000 000, *@example.com), отзывы — примеры, фото созданы ИИ (Google Flow). Кнопка WhatsApp ничего не отправляет. Страницы закрыты от поисковиков (noindex).

- Витрина: `index.html`
- Mesa Lumbre (Costa Blanca, ES/EN/RU): `mesa-lumbre/`
- Taula Clara (València, ES/EN): `taula-clara/`
